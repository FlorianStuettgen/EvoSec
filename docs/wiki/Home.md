SOC_Replay is an evidence-first cyber range combining a documented segmented physical lab with a deterministic replay engine for defensive telemetry.

## Core principle

A photograph proves installation. A configuration proves intended state. A replay report proves deterministic rule behavior. A measured lab experiment proves end-to-end behavior. SOC_Replay keeps those evidence classes separate.

The canonical, reviewable source remains the repository documentation under `docs/`.
